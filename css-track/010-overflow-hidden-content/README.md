# Bug #010: The Hidden Message

### The Goal
Display all the text inside the card.

### The Symptoms
The text is cut off and the bottom half is invisible.

### Hints
1. The card has a fixed `height: 100px`.
2. `overflow: hidden` tells the browser to hide anything that doesn't fit.
3. Try changing `height` to `auto` or removing `overflow: hidden`.
 flagship.
