# Bug #005: The Vector Violation

### The Goal
Access elements of a vector safely.

### The Symptoms
The program crashes with an error: `std::out_of_range`.

### Hints
1. Standard C++ vectors are zero-indexed.
2. If the size is 3, indices are 0, 1, 2.
