# Bug #007: The Double Default

### The Goal
Use a function with a default parameter.

### The Symptoms
Compiler error: `error: default argument given for parameter` or the program doesn't compile correctly.

### Hints
1. Default parameters should only appear in the **declaration** (or definition if there's no separate declaration).
2. Don't repeat the default in both places.
