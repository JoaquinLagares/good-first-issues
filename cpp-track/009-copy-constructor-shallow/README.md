# Bug #009: The Double Delete

### The Goal
Copy a String object safely.

### The Symptoms
The program crashes with "double free" or "heap corruption" error.

### Hints
1. When a class manages dynamic memory (using `new`/`delete`), provide a custom copy constructor.
2. The copy constructor should allocate new memory and copy the data, not just copy the pointer.
3. This is part of the "Rule of Three" or "Rule of Five" in C++.
