# Bug #009: The Void Returner

### The Goal
Create a function that adds two numbers and returns the sum.

### The Symptoms
Compiler error: `error: 'return' with a value, in function returning void`.

### Hints
1. `void` means the function returns "nothing".
2. If you want to return a whole number, use `int` instead of `void`.
