# Bug #010: The Overflow Hazard

### The Goal
Read a name from the user.

### The Symptoms
If you enter a name longer than 4 characters, the program crashes or corrupts other data.

### Hints
1. Always ensure your buffers are large enough for expected input.
2. Use safe functions or specify a width limit in `scanf` (e.g., `%4s`).
