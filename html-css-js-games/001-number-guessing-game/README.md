# Bug #001: Number Guessing Game - The Backwards Hint

### The Goal
Create a working number guessing game where the player receives correct hints about whether their guess is too high or too low.

### The Symptoms
The feedback messages are completely backwards. When you guess too high, it says "Too low!" and vice versa.

### Hints
1. Check the conditional logic in the feedback messages.
2. The messages for each case are in the wrong order.
3. Look at the conditions and their corresponding feedback strings.
