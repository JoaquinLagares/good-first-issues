# Bug #004: Memory Card Game - The Permanent Flip

### The Goal
Create a working memory card game where non-matching cards flip back.

### The Symptoms
When you flip two cards that don't match, they stay flipped instead of turning back over. You can only see one set of cards.

### Hints
1. Look at the `checkMatch` function.
2. The code to flip cards back is commented out.
3. When cards don't match, they should remove the 'flipped' class and clear their text content.
