# Bug #004: The Type Mismatch

### The Goal
Create a sentence combining text and a number.

### The Symptoms
Error: `TypeError: can only concatenate str (not "int") to str`.

### Hints
1. Convert the integer to a string using `str()`.
2. Or use f-strings: `f"I have {count} {message}"`.
