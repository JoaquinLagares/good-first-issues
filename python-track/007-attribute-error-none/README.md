# Bug #007: The Null Operation

### The Goal
Convert a name to uppercase.

### The Symptoms
Error: `AttributeError: 'NoneType' object has no attribute 'upper'`.

### Hints
1. `None` is a special Python value representing "nothing".
2. You cannot call methods on `None`.
3. Check if the variable is `None` before using it: `if name is not None: result = name.upper()`.
