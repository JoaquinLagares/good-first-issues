# Common Programming Bugs Documentation

This folder contains detailed documentation about 10 of the most common programming bugs that beginners encounter.

## Bugs Covered

1. **Off-by-One Error** - The classic fence-post problem
2. **Null/None Reference Exception** - Accessing properties of null values
3. **Type Mismatch** - Mixing incompatible data types
4. **Uninitialized Variables** - Using variables before assignment
5. **Logic Inversion** - Inverted conditional logic
6. **Memory Leak** - Resources not properly released
7. **Infinite Loop** - Loops that never terminate
8. **Copy vs Reference** - Shallow vs deep copying confusion
9. **Race Condition** - Concurrent access issues
10. **Integer Division** - Unexpected integer truncation

Each file contains examples, explanations, and solutions.
