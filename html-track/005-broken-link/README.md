# Bug #007: The 404 Link

### The Goal
The user should be able to navigate to the "About Us" page.

### The Symptoms
Clicking the link results in a "File not found" or 404 error in the browser.

### Hints
1. Inspect the `href` attribute of the `<a>` tag.
2. Compare the filename in the folder vs the filename in the code.
3. Extension matters! `.htm` is not the same as `.html` if the file is named `.html`.
