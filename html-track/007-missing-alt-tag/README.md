# Bug #009: The Silent Image

### The Goal
Make this image accessible to users who use screen readers.

### The Symptoms
If the image fails to load, or if a visually impaired user visits the site, they won't know what this image contains.

### Hints
1. Every `<img>` tag should have an `alt` attribute.
2. In the `alt` text, describe what the image is (e.g., "Beautiful mountain landscape").
