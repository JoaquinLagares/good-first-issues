# Bug #052: The "Div Soup" Syndrome

### The Goal
Improve the accessibility and SEO of this page by using semantic HTML5 elements.

### The Symptoms
The code works, but screen readers and search engines have a hard time understanding which part is the header, which is the navigation, and which is the main content.

### Hints
1. Replace `<div class="header">` with `<header>`.
2. Replace `<div class="nav">` with `<nav>`.
3. Use `<main>`, `<article>`, and `<footer>`.
