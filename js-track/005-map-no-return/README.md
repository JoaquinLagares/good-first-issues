# Bug #005: The Invisible To-Dos

### The Goal
Display the list of tasks inside the `<ul>` element.

### The Symptoms
The page is blank. If you inspect the `<ul>`, you might see "undefined" or just empty space.

### Hints
1. Look at the code inside `todos.map()`.
2. Arrow functions with curly braces `{}` REQUIRE a `return` keyword.
3. Either add `return` before the string, or remove the curly braces.
