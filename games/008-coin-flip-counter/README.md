# Bug #008: Coin Flip Counter - The Frozen Stats

### The Goal
Track the number of heads, tails, and total flips in a coin flip game.

### The Symptoms
No matter how many times you flip the coin, the counters stay at 0. The stats never update.

### Hints
1. Look at the `flipCoin` function.
2. The code that increments the counters is commented out.
3. Uncomment the lines that increment `headsCount`, `tailsCount`, and `totalFlips`.
